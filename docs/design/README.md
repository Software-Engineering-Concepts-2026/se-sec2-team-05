# Design — mockup ของหน้าเว็บ

ต้นแบบหน้าตาที่อติชาติออกแบบ ใช้เป็นแบบอ้างอิงของ `web/` ตั้งแต่ Issue #84 (ปรับหน้าตา) และ Issue #85 (หน้ารายละเอียดโน้ตกับหน้าโปรไฟล์)

| ไฟล์ | คืออะไร |
| --- | --- |
| [`mockup/index.html`](./mockup/index.html) | mockup แบบคลิกได้ทั้ง 5 หน้าจอในไฟล์เดียว: เข้าสู่ระบบ (1a), ค้นหา (1b), อัปโหลด (1c), รายละเอียดโน้ต (1d), โปรไฟล์ (1e) |
| `mockup/script.js` | สลับหน้าจอและข้อมูลจำลอง ไม่เรียก API ใด |
| `mockup/style.css` | สี ฟอนต์ และ layout ที่ `web/style.css` ยึดตาม |

เปิด `mockup/index.html` ใน browser ได้เลย ไม่ต้องรัน server (ฟอนต์โหลดจาก Google Fonts)

**ส่วนที่ไม่ได้ทำตาม mockup และเหตุผล**

- ข้อความเป็นภาษาไทย ตามหน้าเว็บเดิมของทีม ฟอนต์จึงต้องมีชุดภาษาไทยต่อท้าย (ดู `web/README.md` หัวข้อ "หน้าตา")
- ไม่มีปุ่ม University SSO / Google, ระบบ tag และไฟล์ DOCX เพราะอยู่นอกขอบเขตของระบบ
- ช่อง "Tags" ของหน้าอัปโหลดใช้ช่อง `topic` ที่มีอยู่แทน
