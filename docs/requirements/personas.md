# Personas

ทีมแยกไฟล์ persona ออกเป็นคนละไฟล์ต่อ 1 persona แทนที่จะรวมไว้ในไฟล์เดียว เพื่อให้แต่ละไฟล์อ่านและแก้ง่ายขึ้น ไฟล์นี้เป็น index ชี้ไปยังไฟล์จริง (ไม่ duplicate เนื้อหา):

- [เจมส์ อภิสิทธิ์ ทองมา (Note Seeker)](./personas/note_seeker.md) — นักศึกษาปี 1 คณะบริหารธุรกิจ, persona หลักฝั่งผู้ค้นหาโน้ต
- [พิมพ์ชนก "พิม" วงศ์สุวรรณ (Note Contributor)](./personas/note_contributor.md) — นักศึกษาปี 3 คณะวิศวกรรมคอมพิวเตอร์, persona หลักฝั่งผู้แบ่งปันโน้ต

Scenarios ที่มาจาก persona ทั้งสองอยู่ที่ [`main_scenario.md`](./main_scenario.md)
