# Main Scenario: การตามเนื้อหาให้ทันก่อนสอบกลางภาค

**Persona หลัก:** [เจมส์ อภิสิทธิ์ ทองมา](./personas/note_seeker.md) — นักศึกษาปี 1 คณะบริหารธุรกิจ

---

อีกสามวันจะสอบกลางภาควิชา Principles of Marketing แต่เจมส์เพิ่งนึกขึ้นได้ว่าตัวเองขาดเรียนไปสองคาบติดกันในสัปดาห์ที่แล้วเพราะตารางงานพาร์ทไทม์ชนกับตารางเรียนพอดี เขาเปิดแชทกลุ่มเพื่อนร่วมชั้นเพื่อขอโน้ตสรุปของสองคาบนั้น แต่ไม่มีใครตอบทันที เพราะแชทกลุ่มมีข้อความจากหัวข้ออื่นไหลจนโน้ตเก่าที่เคยมีคนแชร์ไว้จมหายไปในประวัติแชท เขารู้ว่าเวลาที่มีจำกัดมากในคืนนี้ จึงต้องหาทางอื่นเพื่อไม่ให้พลาดเนื้อหาสำคัญก่อนสอบ

เจมส์เปิดเว็บแอป NoteShare ที่เพื่อนเคยแนะนำไว้ ค้นหาชื่อวิชา "Principles of Marketing" แล้วกรองผลลัพธ์ตามช่วงวันที่ของคาบเรียนที่ตัวเองขาด ระบบแสดงรายการโน้ตที่ พิม เพื่อนร่วมชั้นที่ขึ้นชื่อเรื่องจดโน้ตละเอียด ได้อัปโหลดไว้ตั้งแต่หลังคาบเรียนจบ พร้อมระบุหัวข้อและวันที่ชัดเจน เจมส์เปิดดูตัวอย่างเนื้อหาก่อนดาวน์โหลด มั่นใจว่าตรงกับที่ตัวเองต้องการ จึงดาวน์โหลดไฟล์มาอ่านทบทวนและกดขอบคุณ/ให้เครดิตเจ้าของโน้ตในระบบ ภายในเวลาไม่ถึง 10 นาที เจมส์ก็ได้เนื้อหาที่ขาดหายไปครบถ้วน พร้อมสำหรับการอ่านทบทวนก่อนสอบ โดยไม่ต้องรบกวนใครในแชทกลุ่มอีกเลย

---

### โครงสร้างเรื่องเล่า (สำหรับอ้างอิงในทีม)

| องค์ประกอบ | รายละเอียด |
| --- | --- |
| **ฉากและตัวละคร** | เจมส์ นักศึกษาปี 1 ที่ต้องทำงานพาร์ทไทม์ควบคู่กับการเรียน กำลังเตรียมสอบกลางภาค |
| **เป้าหมาย** | ต้องการตามเนื้อหาวิชาที่ขาดเรียนให้ทันก่อนสอบ โดยใช้เวลาน้อยที่สุด |
| **อุปสรรค** | โน้ตจากเพื่อนกระจัดกระจายอยู่ในแชทกลุ่ม หาไม่เจอ ไม่รู้ว่าตรงกับคาบที่ขาดหรือไม่ |
| **ลำดับเหตุการณ์กับระบบ** | ค้นหาวิชา → กรองตามวันที่/หัวข้อ → ดูตัวอย่างเนื้อหา → ดาวน์โหลด → ให้เครดิตเจ้าของโน้ต |
| **ผลลัพธ์** | ได้เนื้อหาที่ขาดหายไปครบถ้วนภายในเวลาสั้นๆ โดยไม่ต้องพึ่งพาเพื่อนโดยตรง |
